# Changelog

## 0.2.0 — 2026-09-18

Complete the local review and recovery workflows: two-person execution reconciliation, citation-bound finding challenges and dispositions, password lifecycle, encrypted signed backup/restore, and whole-state diagnostics. Harden decision/review/session/failure/inventory integrity; protect recovery from active dispatch; bind paged audits to consistent checkpoints; clear browser state at logout; strengthen offline export checks and JSON parsing. Add Windows, CLI, and non-root container acceptance checks, with a pinned base image.

Read `docs/REVIEW_AND_COMPLETION.md` and `docs/UPGRADING.md`. The enterprise integration boundaries remain explicit.

## 0.1.0 — 2026-09-18

Initial runnable local application: authenticated analyst console; case membership; bounded evidence imports; mandatory signed human reviews; distinct-account release approvals; fixed export snapshots; offline verification; declarative research packs; optional audited model assessment; and automated security and functional tests.

The original research and design package is preserved under `docs/design/`. Production enterprise integrations and independent control-plane services remain design requirements, not completed release features.
